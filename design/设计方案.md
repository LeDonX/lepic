# 图站聚合浏览器 UI 设计与实现规范

## 基准版本：亮色毛玻璃主题 · 图片首页 · 排行榜时间筛选

# 一、项目目标

开发一款 Windows 桌面应用「图站聚合浏览器」，聚合多个图片站点，实现图片搜索、排行榜浏览、每日壁纸、收藏、下载等功能。

本次 UI 实现必须以提供的最新设计参考图为唯一视觉基准。

核心设计风格：

- 全窗口毛玻璃背景。
- 背景中存在 3～4 个大型柔和渐变圆形。
- 圆形具有缓慢移动和呼吸效果。
- 左侧菜单直接放置在窗口背景层。
- 右侧图片区域使用独立的不透明白色卡片。
- 图片展示占据窗口绝大部分空间。
- 所有控件采用精致、轻量、现代的浅色设计。

**重要：本次任务是高保真还原，不是重新设计。不得擅自改变布局结构、控件顺序、功能名称、配色和视觉层级。**

# 二、整体页面结构

整个页面分为两个主要视觉层级。

## 2.1 第一层：背景窗口层

整个 Windows 应用窗口使用毛玻璃背景。

背景层包含：

1. 渐变背景。
2. 大型动态圆形。
3. 左侧功能菜单。
4. 窗口标题栏和系统控制按钮。

左侧菜单直接融入背景层，不存在独立的侧栏卡片。

左侧菜单的背景透明，可以直接看到底层的渐变和圆形光影。

## 2.2 第二层：图片展示卡片层

右侧只有一个主要实体卡片。

该卡片是图片浏览和搜索功能的主要容器。

卡片包含：

1. 顶部站点切换。
2. 标签搜索框。
3. 排行榜切换。
4. 时间选择控件。
5. 图片网格。

卡片采用不透明白色背景，具有圆角、细描边和轻微阴影。

不使用毛玻璃效果，不增加多余的悬浮面板。

## 2.3 页面层级示意

```
Windows 应用窗口
│
├── 背景窗口层（全窗口毛玻璃）
│   │
│   ├── 渐变背景
│   ├── 动态大型圆形
│   │
│   ├── 左侧菜单（直接位于背景层）
│   │   ├── 应用图标
│   │   ├── 首页
│   │   ├── 每日壁纸
│   │   ├── 收藏
│   │   ├── 下载
│   │   └── 设置
│   │
│   └── Windows 窗口控制按钮
│
└── 图片卡片层（不透明白色）
    │
    ├── 顶部工具栏
    │   ├── 站点切换
    │   ├── 标签搜索
    │   ├── 排行榜切换
    │   └── 时间选择
    │
    └── 图片网格
```

# 三、窗口及整体尺寸

设计基准：

- 设计画布：16:9。
- 基准尺寸：1600 × 900。
- 支持 Windows 窗口缩放。
- 推荐最小窗口宽度：1024px。

整体布局要求：

- 图片卡片尽可能贴近窗口边缘。
- 上下左右外边距保持统一。
- 建议外边距：12～16px。
- 左侧菜单宽度尽可能收窄。
- 右侧图片区域占据绝大部分空间。

窗口顶部保留自绘标题栏及最小化、最大化、关闭按钮。

标题栏不要设计成厚重的独立工具栏。

# 四、毛玻璃背景设计

这是整个应用最重要的视觉特征之一。

不能使用单纯的白色背景，也不能用普通的 CSS 渐变代替完整的毛玻璃氛围。

## 4.1 背景色彩

采用低饱和度、高明度的多色渐变。

颜色分布：

| 区域 | 主色调     |
| ---- | ---------- |
| 左上 | 浅粉、暖橙 |
| 中上 | 浅粉、淡紫 |
| 右上 | 冰蓝、浅蓝 |
| 左下 | 浅紫、浅蓝 |
| 右下 | 淡蓝、淡紫 |

参考颜色：

- 浅橙：#F6DCC5
- 浅粉：#F5E0E9
- 淡紫：#DCD8FA
- 冰蓝：#C9E3FA
- 强调色：#B9DDFF

整体过渡自然，不允许出现明显的色块分界。

## 4.2 大型圆形背景

背景中放置 3～4 个大型渐变圆形。

设计要求：

- 圆形尺寸较大。
- 部分圆形可以超出窗口边缘。
- 圆形之间允许重叠。
- 使用径向渐变。
- 使用较大程度的模糊。
- 圆形透明度适中。
- 不影响前景文字和控件阅读。

圆形应当形成类似参考图中的柔和光晕，而不是明显的装饰图案。

## 4.3 背景动态效果

所有圆形都具有缓慢的呼吸式动画。

动画包括：

- 缓慢水平移动。
- 轻微上下浮动。
- 轻微缩放。
- 不同圆形采用不同动画周期。

推荐动画周期：20～35 秒。

使用 ease-in-out。

禁止快速移动、闪烁、突然改变颜色。

动画应当足够轻微，不影响长时间浏览图片。

# 五、左侧菜单设计

左侧菜单直接放置在背景窗口层。

**禁止为左侧菜单增加独立的白色卡片、毛玻璃卡片或其他实体背景。**

## 5.1 菜单实际功能

菜单必须严格使用以下五个项目：

1. 首页
2. 每日壁纸
3. 收藏
4. 下载
5. 设置

不得增加独立的搜索菜单。

搜索功能已经放在右侧图片卡片顶部。

## 5.2 菜单布局

从上到下：

1. 应用图标。
2. 首页。
3. 每日壁纸。
4. 收藏。
5. 下载。
6. 设置。

菜单整体保持紧凑，尽量减少横向空间占用。

## 5.3 图标设计

使用统一的线性图标。

建议图标：

| 功能     | 图标     |
| -------- | -------- |
| 首页     | Home     |
| 每日壁纸 | Calendar |
| 收藏     | Heart    |
| 下载     | Download |
| 设置     | Settings |

图标尺寸建议为 20～24px。

菜单文字使用现代中文字体，建议 Microsoft YaHei。

## 5.4 选中状态

以首页作为默认选中菜单。

选中状态：

- 浅蓝色背景。
- 蓝色图标。
- 深色文字。
- 圆角矩形背景。
- 不使用厚重阴影。

未选中状态：

- 无背景。
- 深灰色图标。
- 深灰色文字。

## 5.5 菜单展开与收起

必须支持一键展开和收起。

展开状态：

- 显示图标和文字。
- 宽度建议 180px。

收起状态：

- 只显示图标。
- 宽度建议 64～76px。
- 所有图标居中。
- 隐藏文字。
- 保留展开按钮。

切换动画建议 250～300ms。

**左侧菜单展开和收起时，右侧图片卡片必须同步移动和改变宽度。**

不能采用覆盖式菜单，也不能让左侧菜单悬浮在图片卡片上方。

# 六、右侧图片卡片

右侧图片卡片是整个页面的主要视觉主体。

## 6.1 卡片样式

| 属性   | 建议值       |
| ------ | ------------ |
| 背景   | #FFFFFF      |
| 圆角   | 20～24px     |
| 描边   | #F0F1F5      |
| 阴影   | 柔和浅灰阴影 |
| 透明度 | 100%         |
| 内边距 | 24～28px     |

卡片需要有明显的实体感。

不要使用透明玻璃背景。

不要增加多余的内部卡片。

## 6.2 卡片尺寸

卡片宽度：

```
窗口可用宽度 - 左侧菜单宽度 - 左右间距
```

卡片高度尽可能占满窗口可用高度。

卡片内部图片区域使用剩余空间自适应。

# 七、顶部工具栏设计

这是本次实现中需要严格还原的部分。

**所有控件必须保持在同一水平行，不允许换行。**

控件顺序固定为：

```
站点切换
    ↓
标签搜索框
    ↓
排行榜选项
    ↓
时间选择控件
```

从左向右依次排列。

不能将站点切换放到搜索框后面。

不能将时间控件移动到第二行。

不能因为时间控件状态变化而改变工具栏整体布局。

## 7.1 站点切换

位置：顶部工具栏最左侧。

使用下拉选择框。

支持的站点：

- yande.re
- konachan.com
- wallhaven.cc

默认站点按照应用当前设置确定。

样式：

- 白色背景。
- 浅灰色描边。
- 圆角。
- 右侧下拉箭头。
- 文字深灰色。

建议宽度：150～180px。

站点切换不能使用独立的横向 Tab。

必须使用单个下拉框。

## 7.2 标签搜索框

位置：站点下拉框右侧。

搜索框内容：

- 左侧搜索或标签图标。
- 占位文字：输入标签（用空格分隔）。
- 右侧蓝色搜索按钮。

建议宽度：360～440px。

样式：

- 白色背景。
- 浅蓝灰色细描边。
- 圆角。
- 搜索按钮使用蓝色背景。
- 按钮内使用白色搜索图标。

输入框聚焦时：

- 显示浅蓝色描边。
- 显示输入光标。
- 展开标签联想下拉列表。

标签联想面板：

- 位于搜索框下方。
- 白色实体背景。
- 圆角。
- 轻微阴影。
- 不改变整个工具栏的布局。
- 使用高层级显示，避免被图片遮挡。

## 7.3 排行榜切换

位置：搜索框右侧。

使用横向分段选择控件。

固定四个选项：

1. 热门
2. 日榜
3. 周榜
4. 月榜

默认选中：热门。

整体使用一个连续的圆角容器。

选中项：

- 浅蓝色背景 #B9DDFF。
- 深蓝灰色文字。
- 圆角。
- 轻微过渡动画。

未选中项：

- 透明背景。
- 深灰色文字。

建议整体宽度：350～400px。

四个选项保持相同宽度，文字居中。

# 八、排行榜时间选择控件

这是本次界面特别需要注意的交互逻辑。

时间控件必须始终显示在排行榜右侧。

**无论当前选中热门、日榜、周榜还是月榜，时间控件都必须保持可见。**

不得通过隐藏控件来实现排行榜切换。

不得让时间控件换行。

不得让时间控件出现或消失时导致其他控件移动。

## 8.1 默认状态

应用打开时：

- 默认选中热门。
- 时间控件始终显示。
- 时间控件显示默认日期。
- 时间控件处于禁用状态。
- 不响应鼠标点击。
- 不弹出日期选择器。
- 使用置灰视觉表现禁用状态。

禁用状态建议：

- 降低文字颜色对比度。
- 降低边框和图标对比度。
- 保留正常控件外观。
- 不要完全隐藏。
- 不要改变控件尺寸。

这样可以保证工具栏始终稳定。

## 8.2 日榜

点击日榜：

- 日榜切换为选中状态。
- 时间控件启用。
- 显示日期选择器。
- 默认使用当天日期。
- 用户可以选择具体日期。

日期格式：

```
YYYY-MM-DD
```

例如：

```
2026-11-17
```

## 8.3 周榜

点击周榜：

- 周榜切换为选中状态。
- 时间控件启用。
- 控件切换为日期范围选择器。
- 用户可以选择开始日期和结束日期。

展示格式：

```
开始日期 — 结束日期
```

例如：

```
2026-11-09 — 2026-11-15
```

开始日期不能晚于结束日期。

选择完整日期范围后，刷新对应周榜。

## 8.4 月榜

点击月榜：

- 月榜切换为选中状态。
- 时间控件启用。
- 控件切换为月份选择器。
- 用户选择具体年月。

展示格式：

```
2026年11月
```

不要使用完整日期选择器代替月份选择器。

## 8.5 热门

点击热门：

- 热门切换为选中状态。
- 时间控件恢复禁用状态。
- 时间控件继续显示。
- 不允许打开日期选择器。

## 8.6 状态切换表

| 排行榜 | 默认选中 | 时间控件       | 是否可点击 |
| ------ | -------- | -------------- | ---------- |
| 热门   | 是       | 日期占位       | 否         |
| 日榜   | 否       | 日期选择器     | 是         |
| 周榜   | 否       | 日期范围选择器 | 是         |
| 月榜   | 否       | 月份选择器     | 是         |

# 九、图片展示区域

图片网格是整个应用的核心内容。

图片区域占据右侧卡片内部绝大部分空间。

## 9.1 网格布局

默认采用五列布局。

图片之间保持统一间距。

建议：

- 图片圆角：10～12px。
- 图片间距：14～16px。
- 图片宽高比例：根据图片原始比例或统一卡片规则自适应。
- 使用 object-fit: cover。
- 不显示多余文字说明。
- 不使用厚重边框。

图片网格使用 CSS Grid。

示例：

```
.image-grid {
    display: grid;
    grid-template-columns: repeat(5, minmax(0, 1fr));
    gap: 14px;
    overflow-y: auto;
    overflow-x: hidden;
}
```

窗口宽度不足时自动减少列数：

- 宽窗口：5列。
- 中等窗口：4列。
- 窄窗口：3列。

## 9.2 图片卡片交互

鼠标悬停时可以显示：

- 收藏。
- 下载。
- 查看详情。

悬停层应当轻量，不要遮挡大面积图片。

点击图片进入图片详情界面。

# 十二、响应式布局要求

需要重点保证不同窗口宽度下工具栏不换行。

## 12.1 窗口宽度较大

- 左侧菜单可以展开。
- 图片区域五列。
- 搜索框保持较宽。
- 所有工具栏控件同一行。

## 12.2 窗口宽度约 1024px

- 左侧菜单默认收起。
- 左侧只显示图标。
- 图片区域调整为三列或四列。
- 搜索框适当缩小。
- 站点选择框适当缩小。
- 排行榜选项保持完整。
- 时间控件保持完整。
- 工具栏禁止换行。

## 12.3 窗口缩放

左侧菜单和右侧图片区必须保持联动。

建议采用 Flex 布局：

```
.app-layout {
    display: flex;
    width: 100%;
    height: 100%;
    overflow: hidden;
}

.sidebar {
    flex-shrink: 0;
    transition: width 280ms ease;
}

.main-content {
    flex: 1;
    min-width: 0;
    min-height: 0;
    transition: margin 280ms ease;
}

.gallery-card {
    width: 100%;
    height: 100%;
    overflow: hidden;
}
```

工具栏使用单行 Flex 布局：

```
.toolbar {
    display: flex;
    align-items: center;
    flex-wrap: nowrap;
    gap: 12px;
    width: 100%;
    min-width: 0;
}

.site-selector {
    flex-shrink: 0;
}

.search-box {
    flex: 1;
    min-width: 120px;
}

.ranking-tabs {
    flex-shrink: 0;
}

.time-selector {
    flex-shrink: 0;
    white-space: nowrap;
}
```

注意：实际开发时需要根据窗口宽度对各控件设置合理的宽度约束，不能仅依赖上述示例代码。

# 十三、技术实现规范

建议使用模块化结构。

```
App
│
├── BackgroundLayer
│   ├── AmbientBackground
│   ├── AmbientOrbs
│   ├── Sidebar
│   └── WindowControls
│
└── MainContent
    │
    └── GalleryCard
        │
        ├── Toolbar
        │   ├── SiteSelector
        │   ├── TagSearch
        │   ├── RankingTabs
        │   └── TimeSelector
        │
        └── ImageGrid
```

排行榜使用统一状态变量。

建议：

```
var currentRanking = "hot";
var currentDate = "";
var startDate = "";
var endDate = "";
var currentMonth = "";
```

排行榜切换逻辑：

```
function changeRanking(type) {
```
